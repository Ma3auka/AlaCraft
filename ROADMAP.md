# Roadmap

This document tracks what AlaCraft has shipped and what is planned next.  
Have an idea? [Open a Feature Request](https://github.com/Ma3auka/alacraft/issues/new?template=feature_request.md) or discuss it on [Discord](https://discord.gg/ky7cFDF8JD).

---

## ✅ v2.2 — Builders & Fixers *(released August–October 2026)*

Tools that help you build, fix and share, plus Minecraft 26.3 and an 8th language.

**New tools**
- Farms — six interactive 3D build guides (mob XP, iron, creeper, sugar cane, bamboo, kelp), each tested on a vanilla Java 26.3 server
- Enchantment Cracker — find the enchantments your table will offer and roll the one you want, Java 1.8 – 26.3
- Log Checker — crash logs explained in plain words, with a shareable link
- Developer API — public HTTP API for the Log Checker
- 3D Skin Viewer — any player in 3D with capes, emotes, Ears and Customizable Player Models
- Screenshots — share a screenshot as a link, from the site or straight from the game

**Content**
- Minecraft 26.3 — 98 new recipes with official names in every language
- Seed world maps — biome maps with pins on every seed page, coordinates checked in the game
- Ala Industrial — a guide page for every block and item, with machine recipes
- Six mods on the mods page, all on Fabric and NeoForge

**Platform**
- Chinese (Simplified) — the 8th language
- Accessibility for screen readers and the keyboard
- Spoken page summaries in every language
- Loading skeletons instead of a blank spinner
- Live firework preview and a rebuilt /tellraw editor

## ✅ v2.1 — Tools Expansion *(released June–July 2026)*

**New tools**
- Block IDs Reference — every vanilla block and item ID, modern and legacy, with `/give` commands
- Paintings Catalog — all 50 Minecraft paintings with sizes, artists, and `/give` commands
- Seed Map — browser-rendered interactive biome map for any Java seed
- XP & Level Calculator — level ↔ experience conversion with enchanting reference
- Stack Calculator — item quantities to chests, shulker boxes, and inventories
- Create 3D Block — upload textures for all 6 faces, export transparent PNG
- Potion Generator — custom potions with `/give` output
- Our Mods page — AlaLoot, AlaHorde, AlaAggro with CurseForge and GitHub links

**Content additions**
- 116 furnace and smelting recipes added to the crafts catalog
- 29 in-world interaction recipes (no crafting table required)
- Sulfur Cube guide — all 12 archetypes from Minecraft 26.2 Chaos Cubed
- Achievement Generator — Minecraft advancement-style PNG images
- Ala Industrial — tech mod for Fabric and NeoForge, plus a detail page for every mod

**Platform**
- Email verification flow improved — clear confirmation and recovery pages
- Public changelog page at `/changelog`

## ✅ v2.0 — Community Platform *(released May 2026)*

- Community Portal — player posts, reactions, shared presets
- 7 languages — English, Russian, Ukrainian, Spanish, French, German, Japanese
- 1,332+ block reference pages with multilingual descriptions
- New tools: Nether Calculator, Fireworks Builder, Tellraw Editor, Flat World Generator, Stronghold Finder, Custom Crafts Creator, Seeds Catalog, Achievement Generator
- Automated sitemap with `hreflang` per locale
