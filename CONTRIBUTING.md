# Contributing to AlaCraft

AlaCraft is a free Minecraft tools platform — you can contribute without writing a single line of code.

---

## How to contribute

### Report a bug

If a tool gives wrong output, a page is broken, or something behaves unexpectedly:

1. **Search first** — check if the issue is already open: [Browse open issues](https://github.com/Ma3auka/alacraft/issues)
2. **Open a bug report** — use the [Bug Report template](https://github.com/Ma3auka/alacraft/issues/new?template=bug_report.md)
3. **Or reach us on Discord** — [discord.gg/ky7cFDF8JD](https://discord.gg/ky7cFDF8JD)

### Suggest a feature or new tool

Have an idea for a calculator, generator, or content page?

- [Open a Feature Request](https://github.com/Ma3auka/alacraft/issues/new?template=feature_request.md)
- Or discuss it on [Discord](https://discord.gg/ky7cFDF8JD)

### Report incorrect content

The site has 2,400+ recipes, 2,000+ block guides, 50 painting entries, seed guides and 3D farm guides. Errors happen.

**What to report:**
- Wrong crafting recipe ingredients or output
- Incorrect block description, stats, or drop information
- Painting size or artist attribution mistakes
- Outdated information after a Minecraft update
- Seed coordinates that don't match your world
- A farm guide that doesn't work as described in your version
- Tool producing wrong results (Enchantment Cracker, Stronghold Finder, Log Checker, Nether Calculator, etc.)

**Where to report:**
- Discord: [discord.gg/ky7cFDF8JD](https://discord.gg/ky7cFDF8JD)
- GitHub: [Open an issue](https://github.com/Ma3auka/alacraft/issues/new?template=bug_report.md) with the page URL and the correct value

### Improve translations

AlaCraft is available in 8 languages: English, Russian, Ukrainian, Spanish, French, German, Japanese, and Chinese (Simplified).

If you spot a mistranslation or missing text:

- Discord: [discord.gg/ky7cFDF8JD](https://discord.gg/ky7cFDF8JD)
- Or open a GitHub issue with the language, page URL, and the correct text

---

## Community guidelines

- Be respectful and kind — players of all skill levels and languages use AlaCraft
- Write in English in GitHub Issues so everyone can follow
- No spam, self-promotion, or off-topic content
- Use the appropriate channel or issue template — it helps us respond faster
